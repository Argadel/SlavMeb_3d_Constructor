# Славная мебель — 3D-конструктор кухни, MVP 1.3

Техническая версия для проверки базовой механики помещения, каталогов и разных типов кухонных модулей.

## Что есть в версии 1.1

- Вкладка «Помещение» с 2D-планом, независимым перемещением стен, масштабированием колесом и панорамированием ПКМ.
- Вкладка «Модули» с 3D-комнатой, вращением камеры, автоматическим скрытием ближайшей стены и расширенной сеткой.
- Индивидуальный цвет фасада для каждого модуля; новый модуль наследует цвет последнего добавленного.
- Слева — все изменяемые настройки; справа — характеристики выбранного элемента, смета и стоимость.
- Нижние напольные модули не двигаются по высоте.
- Настенные модули можно двигать по высоте мышью и задавать точное значение.
- Привязка к стенам, snapping к соседним модулям и проверка пересечений.
- В каждой категории каталога теперь есть один тестовый объект из прайса.

## Тестовые модули

1. Нижние: НМ1Д_600, арт. 1.1.4 — 600×500×820 мм — 2 860 ₽.
2. Верхние 720: ВМ2Д_600, арт. 2.1.9 — 600×300×720 мм — 2 750 ₽.
3. Верхние 900: 9ВМ2Д_600, арт. 2.3.5 — 600×300×900 мм — 3 190 ₽.
4. Антресоли: ВМА1_600, арт. 2.7.4 — 600×300×360 мм — 1 650 ₽.
5. Пеналы: ПД_2Д_2158, арт. 3.1.1 — 600×550×2158 мм — 6 820 ₽.

Пенал в этой версии имеет отдельную тестовую геометрию: высокий корпус, цоколь, два фасада и нишу с условной духовкой.

## Запуск

В папке проекта:

```bash
python -m http.server 8080
```

или в Windows:

```bash
py -m http.server 8080
```

После этого открыть:

http://localhost:8080

Можно также использовать `start-windows.bat`.


## Исправление 0.8 — антресоль и потолок
- Антресоль теперь регулируется по высоте мышью и точным числом.
- Максимальная высота низа всегда равна: высота комнаты − высота модуля.
- Модуль физически не может выйти выше потолка.
- Для ВМА1_600 минимальная тестовая высота низа снижена до 1450 мм, чтобы сохранить диапазон регулировки даже в комнатах высотой 2200–2600 мм.


## Что изменилось в 1.0
- У каждого размещённого модуля появился небольшой полупрозрачный белый 3D-указатель лицевой стороны.
- Стрелка ориентируется вместе с модулем и всегда показывает направление фасада внутрь помещения.
- Для напольных модулей и пеналов указатель расположен у пола перед фасадом.
- Для верхних модулей и антресолей указатель располагается под самим модулем.
- Указатели вынесены в отдельную 3D-группу и не участвуют в коллизиях, выборе модуля, расчёте габаритов и смете.


## Что изменилось в 1.0

- Стрелка лицевой стороны показывается только у выбранного модуля.
- При выборе другого модуля стрелка переключается на него.
- При снятии выделения стрелка исчезает.
- Во время перетаскивания выбранного модуля стрелка перемещается вместе с ним.


## Что изменилось в 1.1
- Объёмная стрелка заменена на обычную плоскую белую стрелку без 3D-формы и теней.
- Стрелка показывается только у выбранного модуля.
- Она лежит у самой нижней плоскости 3D-модели выбранного объекта и направлена наружу от фасада.
- Для верхних модулей и антресолей стрелка находится на нижней отметке самого модуля, а не на полу.
- Для нижних модулей и пеналов стрелка располагается непосредственно над полом у нижней границы модели.
