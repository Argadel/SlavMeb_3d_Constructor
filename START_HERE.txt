СЛАВНАЯ МЕБЕЛЬ — v1.3.40. РАСШИРЕННАЯ АДМИНКА (ЛОКАЛЬНЫЙ ТЕСТ)

1. Остановите старый сервер (Ctrl+C). Распакуйте архив полностью в отдельную папку.
2. Чтобы сохранить пароль, опубликованные цены и скидку, скопируйте из предыдущей папки два файла admin-private/account.json и admin-private/pricing.json в одноимённую папку новой версии. Не передавайте их третьим лицам. Если файлов нет, при первом запуске задайте пароль заново.
3. Запустите start-windows.bat (Python 3.10+), либо python server.py из папки проекта. Устанавливать дополнительные библиотеки не нужно. При первом запуске на Windows появится окно создания пароля (12–256 символов). При отсутствии Tk используется скрытый ввод в консоли.
4. Конструктор: http://127.0.0.1:8080/ ; админка: http://127.0.0.1:8080/admin/ ; логин admin.
5. Цены: измените отдельную цену или массово измените все модули, выбранную категорию, результаты поиска либо столешницы. Изменения остаются в черновике.
6. Excel: скачайте опубликованный XLSX, измените столбец B (цена), сохраните XLSX и загрузите в черновик. Артикулы в A должны быть текстом; один лист, файл до 2 МБ. Можно импортировать часть строк. Исходный производственный прайс с фото напрямую не подходит. Формулы в A/B не поддерживаются.
7. Скидки: одна акция с областью действия (все модули, категория, артикул, столешницы, весь заказ) и необязательными датами. Без суммирования.
8. Нажмите «Проверить и опубликовать», сравните старые и новые значения, затем подтвердите публикацию. Открытый конструктор обновляет цены при переключении вкладки или периодической проверке (после выхода из активного поля ввода/перетаскивания).
9. История: до 100 предыдущих версий сохраняются автоматически при публикации. Восстановление загружает старую версию в черновик; затем подтвердите публикацию. Резервная копия JSON содержит опубликованные цены и акцию, не содержит пароль. Храните файл отдельно.
10. Безопасность: пароль можно поменять в админке; потребуется текущий пароль. После смены все сессии завершаются, войдите снова. Неопубликованный черновик не сохраняется после выхода/перезагрузки.

ВАЖНО: только локальный тест. Сервер слушает 127.0.0.1, HTTP без TLS. Для публикации на сайте необходим производственный сервер, HTTPS, проверка безопасности и серверный пересчёт отправляемых заказов. Не используйте python -m http.server из корня проекта: это может раскрыть приватные данные. Three.js по-прежнему требует доступ к CDN. Проекты сохраняются браузером по адресу 127.0.0.1:8080.
