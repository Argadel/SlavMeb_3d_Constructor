Размеры комнаты
Как изменить помещение Перетащите левую/правую стену — изменится длина. Перетащите верхнюю/нижнюю стену — изменится ширина. Высота задаётся числом. ПКМ по сетке — перемещение, колесо — приблизить/отдалить. Размеры автоматически сохраняются для 3D.

Настройки выбранного модуля
Выберите модуль в 3D, чтобы изменить доступные параметры.
Новый модуль получает цвет последнего добавленного модуля.
Высоту можно менять и мышью — перетаскивайте настенный модуль вверх/вниз по стене. Система не позволит выйти выше потолка.
Этот модуль устанавливается на пол, поэтому его высота фиксирована.
Как работать в 3D ЛКМ по пустому месту — вращение камеры. Колесо — масштаб. Зажмите модуль и тяните — перенос к другой стене. Модуль автоматически «прилипает» к стене и соседним модулям.
