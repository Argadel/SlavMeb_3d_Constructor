Первый запуск Windows: start-windows.bat открывает отдельное окно создания пароля (символы отображаются звёздочками). Логин admin. Если окно недоступно, используется обычный защищённый ввод в командной строке. Для принудительного запуска в консоли: py -3 server.py --console-password. Уже созданный пароль не изменяется. Сборка только для локальной проверки.
